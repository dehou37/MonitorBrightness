# MonitorBrightness
There are no software applications to control monitor's brightness. This is an app to do that :)

PreRequisites:
- Requires monitor to be DDC/CI compatible (setting has to be turned on)
- Disable smart app control

Steps to run:
1. Run publish.bat file 

Features:
1. To increase brightness - Ctrl + Alt + J, to decrease brightness - Ctrl + Alt + k
2. Upon closing the application, it will be minimized to system tray. 
3. A popup is briefly shown for 2  seconds when brightness is increased or decrease
